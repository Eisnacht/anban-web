# 安伴网页版（UK 安伴）

> 守护留学每一次出行 —— 行程共享、到站报平安、紧急求助，让家人不必反复追问「你到了吗」。

面向**在英国留学的中国学生**与其**国内家人（守护者）**的安全守护 web 应用。前端为 React + Vite 单页应用，可静态托管于 GitHub Pages。当前版本为**浏览器本地演示版**。

---

## 一、应用场景

**要解决的问题**：留学生独自在外，家人难以实时掌握其安全状况，只能反复询问；遇到突发情况时，缺少快速求助并同步通知家人的通道。

典型使用场景：

| 场景 | 应用方式 |
| --- | --- |
| 夜间独自回家、夜跑 | 开启「防护计时」，家人持续可见位置；计时到期未取消，自动向守护圈请求安全确认 |
| 跨城出行（如往返剑桥、去曼彻斯特） | 创建行程 → 家人同步出发与预计抵达时间 → 到站一键报平安 → 超时未确认自动提醒 |
| 感觉被跟踪、遇到可疑人员 | 长按 1 秒发起 SOS，自动附带时间与位置，生成可出示给当地路人或警方的**英文求助内容**，并通知守护圈 |
| 语言/安全咨询（如接到自称使领馆的转账电话） | 向「AI 安全顾问」提问，获得结合英国本地场景的可执行建议 |
| 出发前准备 | 按「证件与财务」等清单逐项打勾（护照 + BRP 复印件、CAS / Offer 打印件等） |

> 演示账号：统一密码 `123456`；可用 `13800000002 / 123456`（妈妈账号）从守护者视角查看效果。

## 二、主要亮点

1. **双向守护圈机制**：生成 6 位邀请码（一次性、24 小时有效），对方填入后双向加入；家人可查看位置与行程，成员加入/退出/暂停共享均有动态通知。
2. **精细的位置隐私控制**：提供「精准 / 模糊」两档共享精度（模糊档约有误差范围）；默认对所有人隐藏，仅在本人主动授权后共享，且可随时暂停。浏览器无法后台定位时，支持手动选点打卡。
3. **行程全流程守护闭环**：创建 → 开始即自动共享位置 → 轨迹同步与回放 → 一键报平安 → 超时自动提醒，覆盖一次出行的完整周期。
4. **SOS 一键紧急求助**：长按触发，自动记录时间与位置，生成英文求助文案可直接出示给英国路人或警方，同时即时通知守护圈，并明确引导拨打 999 / 112。
5. **本地化 AI 安全顾问**：读取实时行程、位置与守护圈状态，针对英国具体处境（报警、使领馆诈骗、房东纠纷、深夜出行等）给出 200 字以内的行动建议。密钥设计上由服务端函数托管，开通后端后无需改代码即可生效。
6. **防护计时 + 模拟来电**：针对夜间独行场景的脱身与安心工具，到期未取消会自动请家人确认安全。
7. **留学安全锦囊**：内置行前清单、反诈提示与英国生活安全提示（银行卡激活、备用钥匙、入住拍照留证等）。
8. **零门槛、易部署**：预置演示数据与账号体系，纯静态前端可直接托管于 GitHub Pages，无需自建前端服务器。

## 三、当前不足

1. **数据仅存于本地浏览器**：账号、位置、行程与提醒均保存在浏览器 `localStorage`（键名 `uk-anban-web-v1`）；清除浏览器数据或换设备后不同步。注册登录为**本地模拟**，不产生真实短信。
2. **AI 顾问后端尚未开通**：生成建议依赖服务端函数托管模型密钥，当前后端服务未开通，AI 顾问暂时无法返回答案（页面已做降级提示）。
3. **无法后台持续定位**：受网页平台限制，不能像原生 App 一样在后台持续定位，需用户授权浏览器定位或手动选点。
4. **底图为示意图**：地图为示意底图，非导航用途，不可用于实际导航。
5. **不替代紧急救援**：应用明确声明不能替代当地紧急救援，遇危险应第一时间拨打 999 / 112。
6. **流式输出兼容问题**：部分运行环境下 SSE 流解码异常（提示「当前运行环境不能解码二进制 SSE」），会影响 AI 顾问的流式输出。
7. **仍为演示定位**：数据均为模拟，尚未接入真实账号体系、消息推送与生产级后端服务。
